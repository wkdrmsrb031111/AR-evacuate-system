AR 대피 앱 확인 방법

1. GitHub에서 초록색 Code 버튼을 누릅니다.
2. Download ZIP을 누르고 압축을 풉니다.
3. 압축을 푼 폴더에서 아래 파일을 순서대로 더블클릭합니다.

   ① 친구용_1_최초설치.cmd (처음 한 번만)
   ② 친구용_2_앱실행.cmd
   ③ 친구용_3_예제데이터등록.cmd (예제가 없을 때 한 번만)

4. 브라우저에서 카메라 앱이 자동으로 열립니다.
5. '등록된 장소 불러오기'를 누릅니다.
6. '[테스트] 가상 회사 · 2층 · ai 듣기'를 선택합니다.
7. '가장 가까운 비상계단 안내 시작'을 누릅니다.

주의
- Python 3.12와 Node.js가 먼저 설치되어 있어야 합니다.
- 실행하면서 열리는 서버 창과 웹 창을 닫으면 앱도 종료됩니다.
- Windows 보안 경고가 뜨면 파일을 직접 만든 팀 프로젝트인지 확인한 후 실행합니다.
- 카메라 주소: http://127.0.0.1:5173/camera.html
- 관리자 주소: http://127.0.0.1:5173/
