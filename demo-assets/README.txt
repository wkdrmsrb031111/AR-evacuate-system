시연용 가상 장소 사진

4장의 사진은 내장 이미지 생성 도구로 만든 합성 이미지입니다.
모든 이미지 하단에 ‘시연용 이미지 · 실제 장소 아님’을 표시했습니다.
실제 마산대학교 또는 특정 회사의 건물 모습·배치·대피 동선이 아닙니다.

demo-room.png: ai 듣기 표지판과 나무 문.
demo-corridor.png: 복도 갈림길 표지판과 파란 문.
demo-east-stairs.png: 동쪽 비상계단 표지판과 초록 문.
demo-west-stairs.png: 서쪽 비상계단 표지판과 주황 문.

생성 프롬프트 요약:
밝은 한국 사무실의 가상 출입문을 눈높이에서 촬영한 사실적인 4:3 사진.
사람·연기·화재·실제 기관 로고 없이 장소 이름을 크게 표시.
하단 노란 배너에 ‘시연용 이미지 · 실제 장소 아님’ 표시.
각 사진의 문 색과 장소 표지판을 위 목록과 같이 구분.

[테스트] 가상 회사 / 2층에 일반 장소·복도·동쪽 계단·서쪽 계단을 등록합니다.
기본 경로: ai 듣기 → 복도 갈림길(8m) → 동쪽 비상계단(12m) = 20m.
대체 경로: ai 듣기 → 서쪽 비상계단 = 60m.
동쪽 계단 연결을 통행 불가로 등록하면 60m 경로로 우회합니다.
별도로 기존 ‘마산대학교 미래관 / 5층 / ai 듣기’에는 같은 합성 사진을 테스트로 연결합니다.
실제 건물에는 가상 복도·계단·경로를 추가하지 않습니다.

등록 스크립트: scripts/seed_demo_photos.py
이미 존재하는 장소·연결·사진은 덮어쓰지 않습니다.
서버의 전체 데이터는 작업 전 server/data/before-demo-photos-*.sqlite3로 백업합니다.
